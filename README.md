### Data, Machine Learning & Web Development Intern

**PIRANA TECH**  
**2-month Internship**

Developed an **intelligent B2B lead generation, analysis, and targeting platform** for a company specializing in IT solutions and cybersecurity.

The main objective was to automate lead qualification, which was previously performed manually by sales teams, in order to improve organization, efficiency, and the overall prospecting process.

#### System Architecture

The platform follows a three-tier architecture:

- **Frontend:** Bootstrap 5 and jQuery
- **Backend:** Flask / Python
- **Database:** MySQL

#### Lead Qualification Module

- Job title analysis
- More than 100 predefined keywords
- Identification of profiles potentially interested in PIRANA TECH services
- Rule-based qualification approach

#### Company Analysis Module

- Website scraping
- Website content analysis
- Technology maturity assessment
- Industry identification
- Requests and BeautifulSoup integration

#### Segmentation & Scoring

The results from the different analysis modules are combined through a segmentation and scoring engine that:

- Assigns a segment: `Tech`, `Business`, `Marketing`, or `Other`
- Calculates a relevance score out of 100
- Generates a final prediction based on a decision rule

#### Platform Features

- CSV lead import
- Manual lead creation
- Interactive dashboard
- Lead search and management
- Lead deletion and data export
- Real-time individual lead analysis
- Automated email campaigns
- Delay management between email sends

#### Results

- **F1-score: 82%**
- **Conversion rate: 18%**, compared with 10% historically using the manual approach
- **Web scraping success rate: 73%**
